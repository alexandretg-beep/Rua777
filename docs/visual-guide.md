# Guia visual inicial

## Direção

- Jogo 2D em pixel art HD.
- Apresentação em 16:9.
- Cenários detalhados, mas sem poluição visual.
- Personagens legíveis e separados do fundo.
- Paleta natural, levemente fria, ajustável conforme a narrativa.
- Vegetação com movimentos discretos, como folhas balançando.
- Interface simples e integrada ao clima.

## Primeira cena

A rua deve transmitir calma, mudança e uma estranheza muito leve. O protótipo usa formas provisórias até que as artes oficiais sejam adicionadas.

## Nila

Toda arte futura deve respeitar a aparência registrada em `docs/canon.md`. Placeholders precisam ser claramente identificados.
